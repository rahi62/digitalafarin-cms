# DigitalAfarin CMS

یک **Headless CMS سئو-محور برای Django + Next.js** که به‌صورت پکیج قابل نصب طراحی شده است.

## نصب

```bash
pip install "digitalafarin-cms[all]"
npm install @digitalafarin/cms-next
```

یا برای اتصال خودکار پروژه موجود:

```bash
npx @digitalafarin/cms-cli init --backend backend --frontend frontend
```

این مخزن نسخه Community است و تحت Apache-2.0 منتشر می‌شود. امکانات تجاری مانند Cloud، AI SEO، Audit پیشرفته، Agency و White-label می‌توانند در محصولات جداگانه ارائه شوند.

برای انتشار عمومی مرحله‌به‌مرحله، فایل [`docs/PUBLISHING.fa.md`](docs/PUBLISHING.fa.md) را ببینید.
