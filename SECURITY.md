# Security Policy

## Supported versions

Until 1.0, security fixes target the latest released minor version.

## Reporting a vulnerability

Please do **not** open a public GitHub issue for an undisclosed vulnerability.

Use GitHub Private Vulnerability Reporting on the repository when enabled, or contact the project owner through the official DigitalAfarin contact channel. Include reproduction steps, affected versions, impact and any suggested mitigation.

Never include production credentials, private customer data or access tokens in a report.
